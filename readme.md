# vi_annotator

本ツールは，自動外観検査システム開発のために画像アノテーション作業を支援する軽量UI付きアノテーションツールです．時間がない中でも必要最低限の操作でアノテーションを完了できます．

## 特長  
- シンプルなUIで素早く操作可能  
- アノテーション結果をすべてJSON形式で保存  
- 不要な画像を除去するフラグ機能を搭載  

## できること  
以下の情報を，プロジェクトごとにまとめてJSONに保存します：  
1. **画像パス**  
2. **画像のタグ**  
3. **BBox（バウンディングボックス）の座標**  
4. **BBoxのタグ**  
5. **BBoxの位置情報**（テキストでの説明）  
6. **不要画像フラグ**（チェックを入れると，除去対象としてマーク）

## 動作環境  
- Python 3.8 以上  
- 必要ライブラリ：`tkinter`, `json`（標準ライブラリ）
